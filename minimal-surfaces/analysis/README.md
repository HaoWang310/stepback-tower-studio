# 竖向排布分析（极小曲面沿竖直方向排成塔楼）

规则（2026-11-25 确认）：

1. **每个曲面只与自身竖向排布**，不加楼板。
2. **003–006 有两种朝向**，在 app 里用「塔楼朝向」切换。
3. 上下两端尽量截在水平镜像面上，所以上下段的接缝是光滑的。

## 变化方式（还没定）

**实测数据**：相邻两段参数相差 Δa 时，接缝处错开的最大距离占建筑宽度的比例：

| 曲面 | 参数变化 | 接缝错开 |
|---|---|---|
| 006 | Δa = 0.01 | 1.0% |
| 006 | Δa = 0.02 | 1.9% |
| 006 | Δa = 0.05 | 4.3% |
| 002 | Δa = 0.005 | 0.8% |
| 002 | Δa = 0.01 | 1.6% |
| 001 | Δa = 0.005 | 2.0% |
| 001 | Δa = 0.01 | 3.9% |

**建议做法**：
- 先做「严格对称 + 参数渐变」：001、002、006 加起止值，显示接缝错开的百分比，超过 1% 时提示。
- 「接缝局部融合」放到第二步。
- 「过渡段数值求解」暂不做。

## 摆放（翻转与对齐平面）· 2026-11-25 已实现

每个曲面的参数面板里，「厚度」上方有一个「摆放」模块：

- **落地面**：原样 / 底 / 顶 / 前 / 后 / 左 / 右。
  - 只用外框的 6 个面。贴在某个面上的边界线长度，达到外框周长的 30% 以上，才算平整、可以选。
  - 塔楼模式下只能选底、顶。
- **翻转**：上下翻转、镜像、绕竖轴 90°（塔楼模式下不能绕竖轴转）。
  - 按钮下方有小字，说明这一步会不会得到新形体。这是按原图参数实测的，见 `图D-翻转与对齐平面.png`。
- **显示对齐平面**：在模型底部画地面网格。
- **高亮接触边**：用青色线标出贴地的截断边。
- **导出 STL**：按当前摆放导出，落地面放在 z = 0。
- **对称面显示**：暂不做。
