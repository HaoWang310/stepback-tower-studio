# 竖向排布分析（极小曲面沿竖直方向排成塔楼）

规则（2026-11-25 确认）：

1. **每个曲面只与自身竖向排布**，不加楼板。
2. **003–006 有两种朝向**，在 app 里用「塔楼朝向」切换。
3. 上下两端尽量截在水平镜像面上，所以上下段的接缝是光滑的。

| 曲面 | 朝向 A | 朝向 B | 每段高度（模型单位） |
|---|---|---|---|
| 001 Scherk–Enneper | 周期轴竖直（只有这一种） | — | 2h（原图参数下 0.957） |
| 002 Helicoidal K–S | 螺旋轴竖直（只有这一种） | — | 一个螺旋周期 |
| 003 Schoen T'–R' | c 轴竖直（棱柱竖立） | a 轴竖直（棱柱横躺） | A：r5 · B：r1 |
| 004 Schoen Manta | 立方体边竖直 | 体对角线 [111] 竖直，六棱柱截面，用粗网格 | A：1 · B：2/√3 |
| 005 Scherk 双周期 | 晶格边竖直 | 晶格对角竖直 | A：π · B：π/√2 |
| 006 KMR | x 方向竖直（端口成水平板） | y 方向竖直（墙体竖立） | A：2f(i)ₓ · B：π |

## 变化方式（还没定）

建议见 `图C-变化方式建议.png`。

**实测数据**：相邻两段参数相差 Δa 时，接缝处错开的最大距离占建筑宽度的比例：

| 曲面 | 参数变化 | 接缝错开 |
|---|---|---|
| 006 | Δa = 0.01 | 1.0% |
| 006 | Δa = 0.02 | 1.9% |
| 006 | Δa = 0.05 | 4.3% |
| 002 | Δa = 0.005 | 0.8% |
| 002 | Δa = 0.01 | 1.6% |
| 001 | Δa = 0.005 | 2.0% |
| 001 | Δa = 0.01 | 3.9% |

**建议做法**：
- 先做「严格对称 + 参数渐变」：001、002、006 加起止值，显示接缝错开的百分比，超过 1% 时提示。
- 「接缝局部融合」放到第二步。
- 「过渡段数值求解」暂不做。
