## 镜像组合 · 2026-11-25 已实现

「摆放」面板里，「翻转」下方加了「组合」：

- **镜像面**：关 / 底 / 顶 / 前 / 后 / 左 / 右，可以选 1–2 个，两个面要在不同方向。面的名字跟落地面一样，以当前看到的外框为准。
- **接缝质量**：打开曲面时实测，用小圆点标出。
  - 青 · 光滑：截断面是曲面的对称面，镜像结果等于把曲面延续下去，不出新形体。
  - 黄 · 微折：平均 ≤ 20°、最大 ≤ 30°，是新形体，接缝基本连续。
  - 橙 · 折角：接缝总长达到该面外框周长的一半，且九成接缝的折角 < 150° 才允许，例如 002 的人字扭转。否则置灰，因为两块几乎不相连，或者局部会贴成双层。
  - 灰：截断面不平整；塔楼模式下顶 / 底也是灰的，因为由「塔楼层数」负责。
- **份数 2–8**：沿第一个镜像面连续镜像，左右交替；第二个面固定 ×2。
- **截平位置**：只对没有平整截断面的曲面（001）出现。选「右」时先在中心到边缘之间竖直切一刀再镜像，默认 25%。
- **高亮接缝**：用接缝质量的颜色画出接缝线。
- **焊成一体**：先镜像中面，接缝点写成同一个精确数值，再整体加厚，导出的 STL 是一个整体。
- 总面数上限约 250 万，超出时自动减少份数。

## 收腰「逐层 / 连续」· 2026-11-26 已实现

- **问题**：塔楼收腰时每层整体缩一个比例，上一层的底边和下一层的顶边差一级（20 层、最细 0.62 时差 4.2%，001 上是 0.31 m），接缝对不上。
- **做法**：塔楼页「收腰」里加「缩放方式：逐层 / 连续」。「连续」让每个点按它所在高度的轮廓线比例缩放，每层顶边的比例等于上一层底边的比例，接缝对齐。
- **自动识别**：载入单体时判断一次。顶、底是切开的边，而且转到某个角度时顶边能和底边重合 90% 以上 → 衔接型，默认「连续」；顶 / 底有水平的面、没有切开的边，或哪个角度都对不上 → 独立单体，默认「逐层」。示例单体和示例楼板是独立单体，和 gh 一样。
- **目录 6 个曲面**：默认摆放下全部是衔接型。侧放时只有 001 沿 x、005 侧放接不上，自动用「逐层」。
- **手动**：可以随时切换，切过之后标签变成「手动」，每个模型各自记住；点标签改回自动。
- **影响范围**：画面、收腰着色、轮廓线、播放动画、导出的 STL / OBJ / 3DM、打印分件和排盘。
- 图：`图S-收腰接缝对齐.png`、`图T-收腰逐层连续效果.png`、`图U-衔接型自动识别.png`、`图V-收腰连续-实现结果.png`

## 打印保形（办法 B）· 2026-11-26 已实现

- **问题**：壁厚是固定的 1.2 mm，比例小时极小曲面的开口和中间的缝会被壁填满，形状变了（图 Y–AE）。
- **做法**：打印面板加「保形」开关。开着时，用户定壁厚，页面按壁厚自动算比例，让整座塔（包括收腰的细层）95% 的地方每个开口和缝至少保留设计宽度的 80%；比例往小取整到 5。剩下极少的窄处按形收薄，预览里标成橙色（图 AF）。
- **默认**：壁厚 1.2 mm；目录曲面开、示例单体关；细长的塔（004、006）推荐分件。
- **结果**（壁厚 1.2 mm）：001 1:195 / 369 mm，002 1:160，003 1:180，004 1:105，005 1:300 / 240 mm，006 1:85。
- **和分析时的差别**：分析只按单体算，没算收腰的细层；算进去后比例要再放大（001 从 1:300 变 1:195）。
