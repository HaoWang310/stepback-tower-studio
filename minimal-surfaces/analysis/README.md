# 塔楼模式分析（竖向叠加 + 楼板）

目标：用目录里的极小曲面生成垂直的塔楼。规则（2026-11-25 确认）：

1. **每个曲面只与自身竖向叠加**，不做不同曲面的混合叠层。
2. **楼板只放在水平镜像面上**。镜像面处曲面与水平面垂直相交，楼板交线干净。

| 曲面 | 竖向叠加方式 | 楼板（镜像面）层距 | 说明 |
|---|---|---|---|
| 001 Scherk–Enneper | 沿竖轴平移 | 2h（原图参数 0.957） | 镜像面 z = (2j+1)h |
| 002 Helicoidal Karcher–Scherk | 螺旋平移（每周期 −2πa） | 无 | 没有水平镜像面，只按周期叠加，不放楼板 |
| 003 Schoen T'–R' | 晶胞上下平移 | r5 = 0.4998 | 1 个竖向周期 = 2 层 |
| 004 Schoen Manta | 晶胞上下平移 | 1 | 晶胞高 2 = 2 层 |
| 005 Scherk 双周期 | 先竖放（数学 y 朝上） | π | 一侧端口成水平板，一侧为竖向翼墙 |
| 006 KMR（Case 1） | 先竖放（数学 x 朝上） | 2·f(i)ₓ（a=0.1 时 3.173） | 两侧端口都成水平板 |

**验证方法**：对生成的塔楼逐层做镜像检验，即关于每块楼板做反射，看反射后的网格是否与原网格重合。
- 5 个有楼板的曲面，平均偏差都为 0（以网格边长为单位）。
- 顶层、底层截面处，曲面法向的竖向分量中位数在 0.01 到 0.1 之间，说明曲面与楼板接近垂直。

**app 里的控制项**（每个曲面都有）：
- **塔楼层数**：0 表示关闭，即原来的展示方式。
- **楼板厚 mm**：0 表示不放楼板。

楼板和曲面一起导出 STL。为了控制面数，总面数上限约 250 万。超出时会自动限制层数并给出提示：例如 Manta 单晶胞最多 12 层，2×2 晶胞最多 3 层。
