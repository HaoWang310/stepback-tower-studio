## 摆放（翻转与对齐平面）· 2026-11-25 已实现

每个曲面的参数面板里，「厚度」上方有一个「摆放」模块：

- **落地面**：原样 / 底 / 顶 / 前 / 后 / 左 / 右。
  - 只用外框的 6 个面。贴在某个面上的边界线长度，达到外框周长的 30% 以上，才算平整、可以选。
  - 塔楼模式下只能选底、顶。
- **翻转**：上下翻转、镜像、绕竖轴 90°（塔楼模式下不能绕竖轴转）。
  - 按钮下方有小字，说明这一步会不会得到新形体。这是按原图参数实测的，见 `图D-翻转与对齐平面.png`。
- **显示对齐平面**：在模型底部画地面网格。
- **高亮接触边**：用青色线标出贴地的截断边。
- **导出 STL**：按当前摆放导出，落地面放在 z = 0。
- **对称面显示**：暂不做。

## 镜像组合 · 2026-11-25 已实现

「摆放」面板里，「翻转」下方加了「组合」：

- **镜像面**：关 / 底 / 顶 / 前 / 后 / 左 / 右，可以选 1–2 个，两个面要在不同方向。面的名字跟落地面一样，以当前看到的外框为准。
- **接缝质量**：打开曲面时实测，用小圆点标出。
  - 青 · 光滑：截断面是曲面的对称面，镜像结果等于把曲面延续下去，不出新形体。
  - 黄 · 微折：平均 ≤ 20°、最大 ≤ 30°，是新形体，接缝基本连续。
  - 橙 · 折角：接缝总长达到该面外框周长的一半，且九成接缝的折角 < 150° 才允许，例如 002 的人字扭转。否则置灰，因为两块几乎不相连，或者局部会贴成双层。
  - 灰：截断面不平整；塔楼模式下顶 / 底也是灰的，因为由「塔楼层数」负责。
- **份数 2–8**：沿第一个镜像面连续镜像，左右交替；第二个面固定 ×2。
- **截平位置**：只对没有平整截断面的曲面（001）出现。选「右」时先在中心到边缘之间竖直切一刀再镜像，默认 25%。
- **高亮接缝**：用接缝质量的颜色画出接缝线。
- **焊成一体**：先镜像中面，接缝点写成同一个精确数值，再整体加厚，导出的 STL 是一个整体。
- 总面数上限约 250 万，超出时自动减少份数。

## 界面：左侧控制、右侧显示 + 中英文 · 2026-11-25 已实现

- **布局（宽度 ≥ 900px）**：左边是控制侧栏，右边整块显示模型。
  - 侧栏默认 380px，拖动右边缘可在 300–640px 之间调宽，宽度记在本机。
  - 右上角「收起侧栏」可以全屏看模型；双击画面回到原图视角。
- **侧栏结构**：
  - 顶部：‹ 目录、中 / EN、曲面名称和说明、预设。
  - 中间分组：外观、形体参数、塔楼、摆放、组合。默认全部展开，点组名可以折叠，折叠后标题旁显示当前状态。
  - 底部固定：厚度、面数和尺寸、「导出 STL」按钮。
- **窄屏（< 900px）**：上面是模型，下面是底部面板，分收起 / 半屏 / 全屏三档，点把手切换或上下拖。
- **中英文**：
  - 默认跟随浏览器语言：zh 开头显示中文，其他显示英文。
  - 手动切换后记在本机；地址后加 `?lang=zh` 或 `?lang=en` 可强制。
  - 目录页和预览页的全部文字都翻译；分析图和 STL 文件名不翻译。
  - 切换语言不会重置模型、视角和参数。

## 单体 → 塔楼 → 打印 · 2026-11-25 已实现

- **合并方式**：两个页面换成同一条顶部步骤条：「‹ 目录 · ① 单体 ② 塔楼 ③ 打印」。
- **用作塔楼单体**：在目录的预览页点侧栏底部的按钮。
  - 送过去的是当前单体的开放中面（按当前的摆放、镜像组合），Z 朝上，换算成米，**一个单体 = 一层 3.6 m**。
  - 单体存进浏览器，自动打开塔楼生成器并载入；层间净高设为 0。
  - 扭转自动设为第一个能对接的角度：001 → 120°、002 → 13.5°、004 → 90°、005 → 90°、006 → 180°。
- **对接检查**：塔楼生成器实测上一层顶边和下一层底边（转过扭转角）重合多少。
  - 接触 ≥ 90% 的角度在扭转滑杆上画青色刻度，拖动时吸附。
  - 接触低于 50% 时会提示。
  - 滑杆范围改为 −180° 到 180°。
  - 顶、底是水平楼板的单体（比如样例单体）不做这项检查。
- **打印**：「③ 打印」把「打印分件」单独成一步，做法不变（每层切半、上半翻面）。
- **限制**：只有在 GitHub Pages 上能直接跳转。在 claude.ai 预览里点按钮会下载单体 STL，再拖进塔楼生成器。
- 图：`图K-单体到塔楼到打印.png`

## 所见即所送 · 2026-11-25 已实现

- **方向**：002、005、006 默认用原图视角显示（画面整体翻转 / 镜像）。现在送去塔楼和导出 STL 都按画面方向，「镜像 · 同原图」按钮也会改变送出和导出的几何。

- 塔楼页「显示」改为三选一：白模 / 目录配色 / 收腰着色。
