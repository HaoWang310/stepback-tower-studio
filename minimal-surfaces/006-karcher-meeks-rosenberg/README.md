## Weierstrass 数据

`KMR-1.nb` 里只存了计算好的图形，没有代码。`KMR-2 (g=1).nb` 有完整代码，其中：

- G = √((z−1/a)(z+a)/((z+1/a)(z−a)))
- dh = dz/z
- f(w) = Re∫ᵢʷ ω − f(a)

KMR-1 所需的 Case 1 是另一种零点和极点的分配，用原作网格确认了下面这一组：

- **G = √((z−a)(z−1/a)/((z+a)(z+1/a)))**
- dh = dz/z
- f(w) = Re∫ᵢʷ ω − f(a)

判断依据有两条：
- a = 0.1 时两个周期之比为 6.3462 : 6.2832 = 1.010，和原网格 x、y 两个方向的跨度比 1.8374 : 1.8192 相同；
- 截断高度 log(1/0.001) = 6.908，等于原网格的归一化尺度。

KMR-2 那一组的周期比是 0.990，所以不是 Case 1。

## 构造

1. 曲面片取 z 平面第一象限：
   - 半径 r 分两段取对数网格，r₀ → a 和 a → 1，r₀ = 0.001；
   - 角度 θ ∈ (0, π/2)。
2. 边界曲线的类型（数值拟合得到）：
   - 虚轴的像：竖直直线，绕它旋转 180°；
   - 单位圆弧的像：水平直线，绕它旋转 180°；
   - 实轴 [r₀, a] 的像：落在平面 y = 0 上，做镜像；
   - 实轴 [a, 1] 的像：落在平面 x = 0 上，做镜像。
3. 两个周期：(4·f(i)ₓ, 0, 0) 和 (0, 2π, 0)。原图画的是 2×2 个周期。
