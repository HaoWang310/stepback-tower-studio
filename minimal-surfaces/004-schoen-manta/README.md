# 004 · Schoen Manta（亏格 19 的蝠鲼面）

- **分类**：C · 三周期 · 立方晶胞
- **用途标签**：结构 · 立面 · 可打印
- **来源**：A. Schoen 发现；K. Brakke 用 Surface Evolver 计算，脚本 `mantaadj.fe`（Brakke 的三周期极小曲面页面）
- **生成方法**：没有公式，只能用数值方法求解：先解一个带自由边的 Plateau 问题，再求伴随曲面，最后用镜像和旋转拼成完整曲面

## 基本区域

基本区域是一个四面体，它的体积是立方晶胞的 1/96。基本区域里的曲面片有四条边界：

| 边 | 伴随前（Plateau 问题） | 伴随后（Manta 曲面片） |
|---|---|---|
| 1 | 直线 v2→v1 | 平面 x = 0 上的曲线 |
| 2 | 直线 v1→v4 | 平面 y + z = 1 上的曲线 |
| 3 | 直线 v4→v3 | 平面 y = x 上的曲线 |
| 4 | 在平面 x + z = 1 上滑动的自由边 | 直线 x = z, y = ½ |

四个顶点是 v1 (0,0,0)、v2 (1,0,0)、v3 (1−α, 2α−1, α)、v4 (0, α, α)，其中 α = 0.203415322692705。

## 求解步骤（solver/）

求解按 .fe 里 `gogo` 的顺序进行：

1. `run1.py 5`：把初始四边形细分 5 次，得到 2113 个顶点。用 Pinkall–Polthier 迭代把面积降到最小：边 1–3 固定，边 4 的顶点只在平面 x+z=1 内移动（`manta.py · constrained_pp`）。收敛后面积 0.30367。
2. `run4.py 5`：
   - 求离散伴随曲面（`conjugate`，余切拉普拉斯泊松方程）。
   - 执行 `frame`：把 z、x、y−x 的最小值平移到 0，再整体除以 v3 的 (y + z)。
   - 把边界点投影回各自的约束平面。
3. `asm.py`：实现 transform_expr，字母**从右往左**作用；生成元 d 带 swap_colors，所以朝向要翻转。
   - `bdbdbd`：12 个基本区域，拼成 1/8 立方 [0,1]³
   - `hfebdbdbd`：96 个基本区域，拼成完整晶胞 [−1,1]×[−1,1]×[0,2]
   - `babadad`：拼成八面体视图

## 验证

- 伴随后的边界落在约束平面上（细分 5 次时，投影前的偏差）：
  - x=0：±7e-4
  - y+z=1：±4e-4
  - y=x：±1e-3
  - 直线 x=z, y=½：±5e-3
- 投影最多移动了 0.0035（晶胞边长为 2）。
- 细分 4 次时的直线偏差是 1.6e-2，所以误差随网格加密而收敛。
- 96 个基本区域拼接后有 589,056 条共享边，朝向全部一致。
- 和原图对比：12 块（1/8 立方）、96 块（立方晶胞）、八面体三种视图的形态都和 Brakke 网页上的一致。

## 说明

- `source/mantaadj-网页翻译版.fe.txt` 是从浏览器翻译过的网页上复制下来的，所以命令名被翻成了中文。复现时按 Evolver 语法还原了几处：
  - `hessian`
  - `min(vertex, y)`
  - `x x/mag`
- Evolver 原流程在 `frame` 之后还会执行 `V; V; hessian` 再松弛一次。这里没有做这一步，因为离散伴随曲面的边界误差已经在 1e-3 量级。
- 颜色沿用 `setcolor`：曲面一侧为黄色，另一侧为灰色。
- 曲面片数据（float32 顶点 + 三角形）直接嵌在目录 app 里，没有单独的文件。`solver/manta_patch_l5.npz` 是同一份数据的 numpy 版本。
